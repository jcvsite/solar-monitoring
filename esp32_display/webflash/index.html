Flash Solar Glance Display

Install this firmware on your 2.8″ ESP32 display from the browser. No PlatformIO or Arduino IDE required.

  1. Use Chrome or Edge on a desktop/laptop (not ESPHome Web).
  2. Plug the display in with a USB data cable.
  3. Click Install, pick the serial port, confirm.
  4. When done, set WiFi on the screen (phone joins SolarDisplay-Setup-XXXX).

Needs firmware files in webflash/firmware/. Build them once with PlatformIO, then run scripts/prepare_webflash.ps1 (Windows) or scripts/prepare_webflash.sh (Linux/macOS). Serve this folder over http://localhost (Web Serial does not work from a raw file:// page). Example: python -m http.server 8765 --directory webflash then open http://localhost:8765.

This is not ESPHome Web — that site only flashes ESPHome images.
